# Indic Tokenizer Study

I'm a BA Hindi (Hons.) student learning NLP. In this project I want to find out:

**Do AI tokenizers treat all languages equally, or do some languages need more tokens to say the same thing?**

## What I plan to do
- Compare how many tokens different tokenizers use for the same sentences in English, Hindi and other Indian languages
- Look at how Hindi words get split up
- Train a small tokenizer of my own, just to learn

## Data
[FLORES-200](https://github.com/facebookresearch/flores) (same sentences translated into many languages)

## Status
Just started. The data is downloaded, and next I will write the token counting script.
